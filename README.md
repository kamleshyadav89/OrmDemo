# OrmDemo

Spring Boot + Hibernate ORM Demo Project

## Description
Yeh project Spring Framework ke saath Hibernate ORM ka basic demonstration hai.  
User Controllers aur database operations ke examples include hain.

## Technologies Used
- Java
- Spring Boot / Spring Framework
- Hibernate ORM
- Maven / Eclipse

## How to Run
1. Project ko Eclipse ya IntelliJ mein import karo
2. Database configuration (`application.properties` ya `hibernate.cfg.xml`) set karo
3. Application run karo
